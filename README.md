# pokemon_app

1. Перед тем как собрать проект, необходимо выполнить скрипт.
Запустите следующий скрипт:

./fast_prebuild_script_mac.sh

Этот скрипт подготовит среду, установит зависимости и выполнит другие необходимые шаги для успешной сборки.

2. Запуск тестов с покрытием
Для выполнения тестов запустите следующий скрипт:

./run_tests_with_coverage.dart
